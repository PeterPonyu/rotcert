# Evaluated research models

The [public Hugging Face collection](https://huggingface.co/PeterPonyu/rotcert-models) provides five saved evaluated
models: four DIOR-R train-only validation-check detectors and one CODrone
EAV-DETR. Duplicate final-checkpoint aliases are not additional models.
An inventory identified 26 further candidate main/supplementary checkpoints,
but their complete checks and public exports are not yet finished. This is
not the complete model inventory of the article.

Weights, portable configurations and parameter-verification records were
downloaded in full without authentication from the [fixed revision](https://huggingface.co/PeterPonyu/rotcert-models/tree/a6303b7ab4effbe6cdde6757bd350bb9e5a802d7).
Each tensor key, dtype, shape and byte value matches the saved evaluated
branch. The release did not rerun full inference or retrain the models.

See [the local model index](MANIFEST.json), the Hugging Face model card,
usage guidance, rights statement and reproduction scope. The software DOI
does not retroactively include the added models. Dataset/provider and
upstream-code terms remain applicable; no blanket MIT license for model
weights or data is asserted. Missing source-level records and historical
model inventory gaps are stated separately.
