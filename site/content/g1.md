G1 conformalizes the GWD score per class. The object that carries the guarantee is the **GWD ball**, reported as a center-offset radius in pixels plus an orientation half-extent — or “unconstrained (near-square)” when heading is not identifiable.

G1 **refuses** when the certifiability floor α<sub>min</sub> = 1/(n<sub>cal</sub>+1) exceeds the target α. Vacuous is a first-class status, not an empty table cell. On DIOR-R, all 20 classes certify for G1 across four architectures; none are refused.

Nominal coverage is 0.90. Out-of-sample checks use R=20 scene-level splits. DOTA overlapping crops are an exchangeability stress case, about 1–1.2 points below nominal.
